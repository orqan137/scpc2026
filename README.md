# SCPC 2026 AI Challenge

Samsung Collegiate Programming Challenge(SCPC) 2026 AI 챌린지에 참가하며 개발한 코드와 검증 기록을 정리한 저장소입니다. 예선 1차에서는 JSON 형태의 작업 상태를 해석하는 결정적 에이전트 하네스를 구현했고, 예선 2차에서는 여러 세션에 걸쳐 공유 맥락을 안전하게 재사용하는 Android 앱 `SafeShare`를 개발했습니다.

## 결과

| 단계 | 결과 | 구현물 |
| --- | --- | --- |
| 예선 1차 | Public 점수 `0.8964`, 전체 640명 중 최종 37위로 예선 2차 진출 | Python 기반 결정적 규칙 엔진 하네스 |
| 예선 2차 | 최종 제출 완료, 본선에는 진출하지 못함 | Android Mobile Agent `SafeShare` |

이 저장소는 본선 진출이나 수상을 주장하지 않습니다. 순위는 참가 당시 확인한 최종 결과를 기준으로 적었습니다.

### 예선 1차: 결정적 에이전트 하네스

예선 1차 과제는 task JSON에 담긴 기기 상태, 대화 기록, 세션 메모와 정책 신호를 해석해 정해진 answer JSON을 만드는 문제였습니다. 외부 모델이나 API를 호출하지 않고 입력에 포함된 근거만으로 대상, 제어 방식, 허용 범위, 정책과 행동 계획을 결정했습니다.

최종 구현은 잘못된 타입과 누락 필드를 안전하게 정규화하고, 명시적인 turn 순서와 최신 상태를 우선하도록 구성했습니다. 또한 근거가 부족하거나 서로 충돌하면 임의로 실행하지 않고 확인을 요청하도록 설계했습니다. 구조·타입·입력 순서를 변형한 34,299건의 퍼즈 테스트에서 예외와 출력 스키마 위반이 발생하지 않았습니다.

자세한 내용과 실행 방법은 [round1/README.md](round1/README.md)에 정리했습니다.

### 예선 2차: SafeShare

`SafeShare`는 업무방과 개인 대화방을 오가며 파일 공유 초안을 준비하는 Android 앱입니다. 사용자가 확인한 목적, 대상 대화방, 역할과 허용 범위를 다음 세션에 재사용하되, 조건이 달라지면 영향을 받은 부분만 보류하고 다시 확인합니다.

핵심 구현은 다음과 같습니다.

- 현재 권한과 정정·철회·삭제를 우선하는 durable state reducer
- 실제 process 종료와 재실행 이후의 부분 복구
- 중복·역순 event와 지연된 outcome을 처리하는 action ledger
- 동일한 snapshot에서 `full`과 `claim-off`를 격리해 실행하는 비교 모드
- 제품 UI와 평가용 Probe가 같은 production core를 사용하는 구조

앱은 실행 중 LLM이나 외부 백엔드를 사용하지 않으며, 실제 메시지 발송과 외부 전송도 수행하지 않습니다. 자세한 내용과 빌드 방법은 [round2/README.md](round2/README.md)에 정리했습니다.

## 공개 범위

저장소에는 참가자가 작성한 코드와 공개용 설명만 포함했습니다. 다음 자료는 재배포 권한과 개인정보·평가 무결성을 고려해 제외했습니다.

- 대회가 제공한 원본 입력, 정답, 공식 Kit와 Probe binary
- 제출 CSV, APK, 서명키와 인증서 자료
- Mission receipt, SAMPLE_EXPORT와 평가 evidence
- 과거 실험 산출물, 캐시와 빌드 결과

따라서 예선 1차 실행에는 참가 권한으로 받은 입력 파일이 필요하며, 예선 2차의 공식 Probe 연동 빌드에는 대회가 제공한 starter AAR가 필요합니다.

## 개발 보조 도구

개발 과정에서 OpenAI Codex와 Anthropic Claude를 구현, 코드 검토, 테스트 작성과 문서 초안에 사용했습니다. 두 도구는 개발 시점에만 사용했으며, 공개한 프로그램은 실행 중에 모델을 호출하지 않습니다.
